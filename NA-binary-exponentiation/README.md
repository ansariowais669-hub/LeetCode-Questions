## 🧩 Problem — Pow(x, n)

### Problem Statement

Implement the function `myPow(double x, int n)`, which calculates:

\[
x^n
\]

That is, given a floating-point number `x` and an integer `n`, return the value of `x` raised to the power `n`.

---

### 📥 Input

You are given:

- `x` — a floating-point number representing the base.
- `n` — an integer representing the exponent.

---

### 📤 Output

Return:

\[
x^n
\]

as a `double`.

---

### 📝 Examples

#### Example 1

```text
Input:
x = 2.00000
n = 10

Output:
1024.00000
